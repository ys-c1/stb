# 双边网格（Bilateral Grid）验收测试

本目录是 `stb_bilateral.h`（位于仓库根目录）的验收测试，全部依赖（C 标准库、
`stb_image_write.h`）均为仓库自带，不引入任何第三方库，也不访问网络。

## 运行

```sh
./run_test.sh
```

脚本会用 `-O2 -Wall -Wextra -Wpedantic -Wshadow` 编译并运行
`test_bilateral_grid.c`，一次性输出全部结果，并把 20 张 PNG 写到
`artifacts_bilateral/`（输入、精确版参考、网格版、两种退化结果，各 4 类图）。

## 实现概述

`stb_bilateral.h` 提供两个公共函数（签名见头文件注释，未改动任何现有接口）：

- `stbbg_bilateral_exact_gray8`：精确（暴力）双边滤波，参考实现。窗口半径
  `ceil(3*sigma_spatial)`，空间/值域高斯权重用预计算 1-D 查表 + 线性插值。
- `stbbg_bilateral_grid_gray8`：双边网格近似，三步：
  1. **splat**：每个像素按 (x, y, 灰度) 三线性累积进 3-D 网格，存
     “加权值之和”和“权重之和”两个体素阵列；
  2. **blur**：对两个阵列分别沿 x/y/z 做可分离高斯模糊（各轴独立半径，
     网格空间 σ 由图像 σ 自动换算）；
  3. **slice**：每个像素在自身 (x, y, 灰度) 处三线性插值两个阵列，相除归一化。

空间/色度网格尺寸（`grid_w/grid_h/luma_levels`）与模糊半径（`blur_radius`，
传 0 表示按 σ 自动）均可在 `stbbg_grid_params` 中配置。

## 退化情形（网格尺寸为 1）

- `grid_w == grid_h == 1`：3-D 网格已无空间分辨率，函数走专用的
  **图像域可分离空间高斯**路径（即“纯空间模糊、与值域无关”这一有明确定义的
  结果），测试用独立编写的空间高斯参考核对，PSNR = 99 dB（逐像素一致）。
- 单轴为 1（如 `grid_w=1, grid_h>1`）：该轴 σ 取 0、使用单位核，不做除法。
- 所有网格间距都是带保护的除法；slice 归一化若遇到零权重则回退为输入值，
  因此任何配置都不会出现除零，输出始终有定义。

## 测试图（256×256 灰度，程序内合成，确定性随机种子）

1. `gradient` 平滑斜坡 + 正弦扰动；
2. `steps` 硬阶跃块；
3. `noise` 高斯噪声 + 正弦（最考验值域量化）；
4. `mixed` 圆盘 + 斜坡 + 硬边 + 噪声的混合。

## 精度/速度/内存权衡（实测，见下）

固定 `sigma_spatial=8, sigma_range=24`，三组网格（PSNR 为四类图上的区间）：

| 档位 | 网格 (gx×gy×gz) | 相对精确版 PSNR | 典型耗时 | 加速比 | 临时内存 |
|---|---|---|---|---|---|
| coarse | 16×16×16 | 41.4–99 dB | ~1.3 ms | 920–990× | 49 KB |
| medium | 32×32×16 | 45.8–99 dB | ~1.8 ms | 650–710× | 197 KB |
| fine   | 64×64×32 | 48.2–99 dB | ~9 ms | 127–141× | 1.5 MB |

（99 dB 表示与精确版逐像素一致，出现在硬阶跃图上；其余三类图的 PSNR 见
程序输出。）

要点：**值域分辨率 gz 对含噪图像的精度是主导因素**（把 gz 从 8 提到 16，
噪声图 PSNR 从 35 dB 升到 45 dB），空间分辨率主要影响边缘定位。精确版在同样
256×256 图上耗时约 1.2 s（窗口半径 24，约 2300 次邻域/像素），它只做标量运算、
不分配临时内存（scratch = 0 B）。精确版本身已与独立的朴素 `exp()` 实现做过
逐像素核对（四种 σ 组合下 max|diff|=0）。

边界约定：clamp-to-edge——邻域**访问**被钳制到图像边界，但空间高斯**权重**
始终使用未钳制的原始偏移，避免边界像素权重被人为放大。

## 验收门槛（程序内自动判定）

- 三组正常网格：PSNR ≥ 38 dB 且加速比 ≥ 5×；
- 退化配置：与独立空间高斯参考 PSNR ≥ 45 dB（实测 99 dB）、无除零、输出有界；
- 非法参数（尺寸 ≤0、σ ≤0、gz>256、空指针）返回 -1 而非崩溃；
- 内存埋点确认所有内部分配均被释放，无泄漏。
